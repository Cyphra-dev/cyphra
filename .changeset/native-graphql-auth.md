Native API auth (#245): `models.<M>.rules` (`read`, `create`, `update`, `delete`, `connect` / `disconnect` per relation, `after.create` / `after.update`), functions of the request's context typed against the generated client and compiled into every statement that reaches the model (relation loads and filters, `_count`, `totalCount`, mutation results, write targets); `authenticated` per model or operation group (`UNAUTHENTICATED`, and for a whole group the model is hidden or not writable for anonymous requests wherever it is reached); field rules, context-only (`read: ({ ctx }) => boolean`: `null` with `FORBIDDEN` where selected, `FORBIDDEN` where filtered or sorted on) or row-dependent (`read: { where }`: `null` on the rows outside it, in results, filters and ordering), with ruled fields generated nullable; `native.jwtContext({ key, user })` (the `compat.v7` verifier) and `native.context(schema, build)` setting `ctx.cyphra`, the request's client with the rules applied (`$unsafe` without). Outside an `update` / `delete` / `connect` rule a node is `NOT_FOUND`; `false` and failing `create` / `after` rules are `FORBIDDEN` (rolled back). `makeSchema` checks rule keys and relations, and calls each `where` rule with an empty context to check the fields it names.
