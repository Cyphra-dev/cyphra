## What every guide has in common

- **One client per process.** `createClient` opens a Neo4j driver with a connection pool. Create
  it once and share it; each guide shows the idiomatic place for that in its framework.
- **Credentials in the environment.** `NEO4J_URI`, `NEO4J_USERNAME` and `NEO4J_PASSWORD`, written
  for you by `cyphra dev` locally, set by you in production.
- **Server side only.** The driver and the credentials never reach a browser bundle.
- **Migrations before the app.** `cyphra migrate deploy` applies pending
  [migrations](/migrations) before new code starts using the schema.
- **Neo4j 5.6 or later**, for example Neo4j Aura, [Cyphra Cloud](/cloud) or the `neo4j:5` Docker
  image that `cyphra dev` starts.
