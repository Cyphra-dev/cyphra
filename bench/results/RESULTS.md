## Not compared

- upsert, neogma: no upsert (createOne with merge MERGEs on every property)
- upsert, graphql: no upsert mutation in @neo4j/graphql
- delete with cascade, neogma: no cascading delete (detach only)
- Relation count, neogma: no relation count API
- aggregate, neogma: no aggregation API
- groupBy, neogma: no aggregation API
- groupBy, graphql: no groupBy in @neo4j/graphql
- 3-hop traversal, neogma: findRelationships returns one row per path, not distinct nodes
- 3-hop traversal, graphql: no traversal without a custom @cypher field
- Shortest path, neogma: no path API
- Shortest path, graphql: no path API without @cypher
- Vector findSimilar (k = 10), neogma: no vector search API
- Vector findSimilar (k = 10), graphql: not compared (vector support differs)
